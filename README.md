# Beutl.Extensions.FocusLines

<img src="assets/icon.png" width="96" height="96" alt="">

集中線などの漫画の効果線を描くBeutlの拡張機能です。ライブラリの「集中線」グループに、次の5種類のオブジェクトを追加します。

表示言語はBeutlの設定に従います。日本語・英語・簡体字中国語・韓国語・スペイン語に対応し、それ以外の言語では英語で表示します。言語を変更した後はBeutlを再起動してください。

| 種類 | 描くもの |
| --- | --- |
| 集中線 | 画面の外から中心へ集まる線。中心の周りは空白になります。 |
| ウニフラッシュ | 中心の空白の周りから、とげのように外へ広がる線。 |
| ベタフラッシュ | 画面を塗りつぶし、中心の空白から光が放射状に伸びる絵。 |
| 流線 | 一方向へ流れる平行な線。 |
| 放射 | 中心から扇形に広がる縞模様。 |

## 使い方

1. ライブラリの「集中線」から種類を選び、タイムラインに追加します。
2. ウニフラッシュ以外は画面全体に描画されます。オブジェクトを選択するとプレビューに中心のハンドルが出るので、ドラッグして中心を動かします。ウニフラッシュは図形と同じように、変形で位置や大きさを変えます。
3. 本数・太さ・空白の大きさなどをプロパティで調整します。どの値もキーフレームで動かせます。

線の配置はシードと時刻だけで決まるので、再生・シーク・書き出しのどれでも同じ絵になります。

## 共通のプロパティ

| プロパティ | 内容 |
| --- | --- |
| 中心 | 画面の中央からの位置（px）です。 |
| 本数 | 線の数です。 |
| 太さ・太さのばらつき | ばらつきは、線を最大でどこまで細くするかの割合です。 |
| 間隔のばらつき | 0%で等間隔に並び、大きくするほど散らばります。 |
| 更新間隔 (秒) | この間隔で線を描き直します。0で描き直しません。 |
| シード | 線の配置を決める乱数の種です。 |
| 塗りつぶし・ストローク | 線の色と縁取りです。ストロークの描画順を「塗りつぶしの下」にすると、重なった線の内側に縁取りが出ません。 |

## 種類ごとのプロパティ

### 集中線

- 「太さ」は、線が画面の端を通る位置での太さです。線は中心側で細くなります。
- 「空白の大きさ」は画面の幅と高さに対する割合です。「ギザギザ」で線の始まる位置をばらつかせます。
- 「ねじれ」で線を渦のように曲げます。
- 既定では0.1秒ごとに描き直し、線がちらつきます。止めるには「更新間隔」を0にします。

### ウニフラッシュ

- 既定は白い線に黒い縁取りです。黒いウニフラッシュにするには、塗りつぶしを黒にしてストロークを外します。
- 「空白の大きさ」と「長さ」はピクセルで指定します。オブジェクトの大きさは、いちばん長い線が届く範囲です。
- 「線の形」は「両端を細く」「外側を細く」「内側を細く」から選びます。

### ベタフラッシュ

- 「塗りつぶし」で画面を塗り、「光」で光を塗ります。中心の空白には下のものが見えます。
- 「光」をなしにすると、光の形に抜けて下のものが見えます。
- 「長さ」は、空白の端から画面の端までに対する光の長さです。

### 流線

- 「角度」が0のとき、左から右へ流れます。「速さ」を0にすると止まります。
- 「長さ」は、線の向きの画面の長さに対する割合です。
- 「空白の幅」で、中央に線を描かない帯を作ります。
- 「線の形」は「両端を細く」「後ろを細く」「前を細く」「細くしない」から選びます。前は線が流れていく側です。

### 放射

- 「線の幅」は、線と隙間を合わせた幅に対する線の幅です。
- 「回転の速さ (°/秒)」で、一定の速さで回ります。
- 「背景」で線の間を塗ります。「ねじれ」で渦巻き模様にします。

## 開発

`Beutl.Extensibility.Sdk` 2.0.0-preview.16 と .NET 11 SDK でビルドします。

```bash
dotnet build src/Beutl.Extensions.FocusLines
```

```bash
dotnet test tests/Beutl.Extensions.FocusLines.Tests
```

テストには、線の形を計算する単体テストと、Beutlの `SceneRenderer` でシーンをヘッドレスに描画して画素を確認するテストがあります。描画した画像は `bin/Debug/net11.0/rendered/` に保存されます。

Beutlにサイドロードして試す場合は、次のコマンドで `~/.beutl/sideloads` に出力します。

```bash
dotnet build src/Beutl.Extensions.FocusLines -p:DebugApplication=true
```

アイコンは `assets/icon.svg` を512pxで書き出したものです。文字は Noto Sans JP Black（SIL Open Font License 1.1）の字形をパスにしています。

翻訳は `src/Beutl.Extensions.FocusLines/Properties/Strings*.resx` で管理します。`Strings.resx` が英語の既定値で、言語別ファイルに同じキーの翻訳を追加します。リソースクラスはビルド時に自動生成されます。
